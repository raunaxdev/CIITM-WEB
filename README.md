# CIITM Academic ERP & Enterprise Portal 🎓

An end-to-end, ultra-modern academic management system built for Chhotanagpur Institute of Information Technology & Management (CIITM), Dhanbad.

🚀 **Live Portal**: [https://ciitm-web.vercel.app](https://ciitm-web.vercel.app)

## ✨ Core Features
- 🔐 **Role-Based Auth**: Dedicated Student & Faculty Portals with first-time password activation.
- 📜 **Digital Repository Hub**: Instant access to verified circulars, syllabus notes, and exam scorecards.
- ⚡ **Result Generator Wizard**: Multi-step marks compilation system for faculty with automated Pass/Fail badges.
- 📁 **Direct Storage Integration**: Upload PDF/Image circulars directly to Supabase Storage.
- 🎨 **Modern EdTech Aesthetics**: Interactive Bento-grid layout, glassmorphic UI, and seamless Dark/Light modes.

## 🛠️ Tech Stack
- **Frontend**: HTML5, Tailwind CSS, Lucide Icons
- **Backend & Database**: Supabase (PostgreSQL, Realtime DB, Auth, Storage)
- **Deployment**: Vercel
